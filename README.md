# Personal Portfolio Website

A responsive personal portfolio website developed for the **CSE 471: Web and Internet Programming** course at Southeast University, Bangladesh.

## 🔗 Live Links
- **Live Site:** https://thecoder-007-007.github.io/MyPortfolio/
- **GitHub Repository:** https://github.com/theCoder-007-007/MyPortfolio

## 🛠️ Tech Stack
- **HTML5:** Semantic markup and document structure
- **CSS3:** Custom styling, Flexbox, CSS Grid, media queries, and themes
- **JavaScript:** Dynamic DOM manipulation, modal components, and theme switcher
- **Deployment:** GitHub Pages

## ✨ Key Features
- Responsive layout across mobile, tablet, and desktop viewports
- Dark/Light mode theme switching using CSS custom properties
- Interactive hero canvas animations and dynamic statistical counters
- Modal dialogs for detailed project presentations
- Client-side contact form validation
